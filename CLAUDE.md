# CLAUDE.md — правила проекта MewMo

MewMo (МяуМо) — детская игра для детей 9–12 лет про котов-пришельцев,
похожая на упрощённый Pokémon GO. Игрок гуляет с телефоном, находит котов
на карте и помогает им вернуться домой.

Автор проекта — начинающий программист. Поэтому:

- пиши простой и понятный код, без хитрых приёмов;
- добавляй подробные комментарии **на русском языке**;
- после каждой задачи коротко объясняй, что сделано и зачем.

## Технологии

- Только чистый **HTML, CSS и JavaScript**.
- **Без** сборщиков (webpack, Vite и т. п.), без npm-зависимостей и без
  фреймворков (React, Vue и т. п.).
- Карта — библиотека **MapLibre GL JS** (версия 5.x, подключается обычным
  `<script>` с CDN jsDelivr) с бесплатными картами **OpenFreeMap**
  (стиль `https://tiles.openfreemap.org/styles/liberty`, API-ключ не нужен).
- В MapLibre координаты пишутся как **[долгота, широта]** — наоборот,
  чем в Leaflet.
- Камера как в Pokémon GO: наклон 60°, объёмные здания, зум 17–18.
- Игрок и капсулы — HTML-маркеры MapLibre (`maplibregl.Marker`), их вид
  задаётся в `style.css`. Не задавать маркерам в CSS `position` и
  `transform` — ими MapLibre двигает маркер.
- **Подпись об авторах карты (OpenFreeMap, OpenMapTiles, OpenStreetMap)
  убирать нельзя** — это обязательное условие использования карт.
- Внешние библиотеки подключаются через `<script>` / `<link>` с CDN
  с точно указанной версией (как MapLibre в `index.html`).

## Файлы

| Файл | Что внутри |
| --- | --- |
| `index.html` | Структура страницы |
| `style.css` | Внешний вид |
| `game.js` | Карта, GPS, игрок, капсулы |
| `encounter.js` | Окно «Знакомство с котом», мини-игры, бой с капитаном и помощники |
| `album.js` | Альбом экипажа (кнопка «Экипаж») |
| `beacons.js` | Маяки у реальных мест (данные карты → маркеры) |
| `captains.js` | Потерявшиеся капитаны у маяков |
| `cats.js` | Каталог котов и капитанов |
| `logic.js` | «Чистая» логика без карты и HTML — её проверяют тесты |
| `tests/` | Автотесты на встроенном `node:test` |
| `PROGRESS.md` | Ход работы, решения, проблемы, идеи |

Скрипты подключаются в `index.html` в таком порядке: MapLibre → `logic.js`
→ `cats.js` → `encounter.js` → `album.js` → `beacons.js` → `captains.js`
→ `game.js`.

Сохранение — только в `localStorage` под ключом `mewmo-save-v1`
(экипаж, капитаны, рыбки, детали, перезарядка маяков по id). Координаты
игрока туда не записываются.

## Проверки перед пушем в main

- `node --check <файл>` для каждого `.js` файла;
- `node --test` — все тесты зелёные (команда `node --test tests/`
  в Node 22 не работает, поэтому без аргумента);
- новую «чистую» логику класть в `logic.js` и покрывать тестами.

## Публикация

- Игра публикуется через **GitHub Pages** из ветки **`main`**
  (папка `/ (root)`).
- Всё, что попало в `main`, сразу становится видно игрокам — проверяй,
  что игра открывается без ошибок.
- Геолокация в браузере работает только по `https`, GitHub Pages это
  обеспечивает.

## Безопасность детей (обязательно)

- **Никакого чата** и никакого общения между игроками.
- **Геолокация не передаётся на сервер.** Координаты игрока используются
  только внутри браузера на его телефоне. Не отправлять их никуда: ни на
  свой сервер, ни в аналитику, ни в сторонние сервисы.
- **Без рекламы, без покупок** и без любых платных функций.
- Не собирать личные данные (имя, возраст, фото, почту и т. п.).
- На стартовом экране — напоминание о безопасности: смотреть по сторонам
  и играть вместе со взрослым.

## Секреты

- **Никогда не добавлять в репозиторий ключи, токены и пароли.**
  Репозиторий и сайт на GitHub Pages видны всем.
- Если для чего-то нужен ключ — сначала обсудить, можно ли обойтись без
  него.

## Язык

- Весь интерфейс игры — **на русском языке**.
- Комментарии в коде и описание в README — тоже на русском.
