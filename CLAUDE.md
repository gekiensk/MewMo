# CLAUDE.md — правила проекта MewMo

MewMo (МяуМо) — детская игра для детей 9–12 лет про котов-пришельцев,
похожая на упрощённый Pokémon GO. Игрок гуляет с телефоном, находит котов
на карте и помогает им вернуться домой.

Автор проекта — начинающий программист. Поэтому:

- пиши простой и понятный код, без хитрых приёмов;
- добавляй подробные комментарии **на русском языке**;
- после каждой задачи коротко объясняй, что сделано и зачем.

## Технологии

- Только чистый **HTML, CSS и JavaScript**.
- **Без** сборщиков (webpack, Vite и т. п.), без npm-зависимостей и без
  фреймворков (React, Vue и т. п.).
- Карта — библиотека **MapLibre GL JS** (версия 5.x, подключается обычным
  `<script>` с CDN jsDelivr) с бесплатными картами **OpenFreeMap**
  (стиль `https://tiles.openfreemap.org/styles/liberty`, API-ключ не нужен).
- В MapLibre координаты пишутся как **[долгота, широта]** — наоборот,
  чем в Leaflet.
- Камера как в Pokémon GO: наклон 60°, объёмные здания, зум 17–18.
- Игрок и капсулы — HTML-маркеры MapLibre (`maplibregl.Marker`), их вид
  задаётся в `style.css`. Не задавать маркерам в CSS `position` и
  `transform` — ими MapLibre двигает маркер.
- **Подпись об авторах карты (OpenFreeMap, OpenMapTiles, OpenStreetMap)
  убирать нельзя** — это обязательное условие использования карт.
- Внешние библиотеки подключаются через `<script>` / `<link>` с CDN
  с точно указанной версией (как MapLibre в `index.html`).

## Файлы

| Файл | Что внутри |
| --- | --- |
| `index.html` | Структура страницы |
| `style.css` | Внешний вид |
| `game.js` | Прогулка: карта, игрок, капсулы, сохранение, сумерки |
| `gps.js` | Надёжный GPS: слежение, «сторож», окно разрешения, журнал и «Проверить GPS» |
| `encounter.js` | Окно «Знакомство с котом», мини-игры, бой с капитаном и помощники |
| `album.js` | Альбом экипажа (кнопка «Экипаж»), задания и сердечки дружбы в нём |
| `beacons.js` | Маяки у реальных мест (данные карты → маркеры) |
| `captains.js` | Потерявшиеся капитаны у маяков |
| `home.js` | Режим «Дом»: убежище, гости, забота о котах |
| `quests.js` | Ежедневные задания |
| `settings.js` | Настройки, «Для взрослых», родительский замок, время игры |
| `sound.js` | Звуки, синтезированные через Web Audio API (без файлов) |
| `art.js` | Картинки в SVG: портреты котов, капсула, маяк, убежище, взлёт, обучение |
| `cats.js` | Каталог котов и капитанов (у каждого поле `chapter` — глава 1 или 2) |
| `launch.js` | Финал главы: «Запустить корабль», сцена взлёта, вступление к новой главе |
| `tutorial.js` | Обучение «Как играть» (6 картинок) |
| `manifest.webmanifest`, `icons/` | Установка игры на телефон (иконка — свой SVG и PNG из него) |
| `logic.js` | «Чистая» логика без карты и HTML — её проверяют тесты |
| `tests/` | Автотесты на встроенном `node:test` |
| `tools/smoke.js` | Проверка игры в браузере (Chromium + Playwright), см. «Как проверять» |
| `PROGRESS.md` | Ход работы, решения, проблемы, идеи |

Скрипты подключаются в `index.html` в таком порядке: MapLibre → `logic.js`
→ `cats.js` → `art.js` → `sound.js` → `encounter.js` → `album.js`
→ `tutorial.js` → `launch.js` → `quests.js` → `settings.js` → `home.js`
→ `gps.js` → `beacons.js` → `captains.js` → `game.js`.
Файл, подключённый раньше, не может при загрузке ссылаться на функции
из файлов ниже — только изнутри обработчиков (через функцию-обёртку).

Сохранение — только в `localStorage` под ключом `mewmo-save-v1`
(экипаж, капитаны, рыбки, детали, перезарядка маяков по id, настройки,
время игры за день, гости, дружба, задания, глава, значки, кто улетел
домой, отставшие, обучение). Координаты игрока туда
не записываются. Новые поля добавлять так, чтобы `cleanSave` заполнял
их значениями по умолчанию — старые сохранения должны работать (с тестом).

Все картинки и звуки — свои, нарисованные/синтезированные в коде
(`art.js`, `sound.js`). Чужие картинки, персонажи и звуки не использовать.

В режиме «Дом» геолокация не запрашивается и карта не создаётся.

## Главы

- Глава 1 — 10 котов, 2 капитана, корабль на 20 деталей. Глава 2
  «Сигнал с орбиты» — 12 котов, 2 капитана, корабль на 30 деталей.
- Коты для капсул и гостей — `pickCatForChapter` (коты текущей главы
  и ~10% «отставших» из прошлой). Счётчики экипажа — через
  `chapterCats(CATS, save.chapter)`, не по всему каталогу.
- Финал есть только у главы 1 (`LAUNCHABLE_CHAPTERS` в `logic.js`).

## GPS

- Слежение запускается только через `startGps()` (`gps.js`): перед новым
  `watchPosition` всегда `clearWatch` старого.
- В `onPosition` сначала строка состояния и точка игрока; всё остальное
  (капсулы, маяки, капитан, сумерки) — через `safely()`, чтобы ошибка
  попала в журнал, а GPS продолжал работать.
- Журнал диагностики и отчёт «Проверить GPS» — **без координат**, только
  в памяти страницы, никуда не сохраняются и не отправляются.

## Как проверять (перед каждым пушем в main)

- `node --check <файл>` для каждого `.js` файла (и `tools/smoke.js`);
- `node --test` — все тесты зелёные (команда `node --test tests/`
  в Node 22 не работает, поэтому без аргумента);
- `node tools/smoke.js` — проверка в браузере: должно быть «ВСЁ ХОРОШО».
  Скрипт сам запускает `python3 -m http.server`, открывает игру
  в Chromium на экране 390×844 с подменённой геолокацией и проходит
  сценарии «Прогулка» (5 точек, альбом, настройки, «Проверить GPS»,
  дом и обратно) и «Нет разрешения». Любая ошибка в консоли — провал.
  Нужны Node.js, Python 3 и Playwright, установленный на компьютере
  глобально (`npm install -g playwright`, `npx playwright install
  chromium`) — в проект npm-пакеты не добавляем. Внешние серверы
  (карта, шрифт, MapLibre) скрипт подменяет заглушками; с настоящей
  сетью — `node tools/smoke.js --real-network`;
- новую «чистую» логику класть в `logic.js` и покрывать тестами;
  новые сценарии — добавлять в `tools/smoke.js`.

## Публикация

- Игра публикуется через **GitHub Pages** из ветки **`main`**
  (папка `/ (root)`).
- Всё, что попало в `main`, сразу становится видно игрокам — проверяй,
  что игра открывается без ошибок.
- Геолокация в браузере работает только по `https`, GitHub Pages это
  обеспечивает.

## Безопасность детей (обязательно)

- **Никакого чата** и никакого общения между игроками.
- **Геолокация не передаётся на сервер.** Координаты игрока используются
  только внутри браузера на его телефоне. Не отправлять их никуда: ни на
  свой сервер, ни в аналитику, ни в сторонние сервисы.
- **Без рекламы, без покупок** и без любых платных функций.
- Не собирать личные данные (имя, возраст, фото, почту и т. п.).
- На стартовом экране — напоминание о безопасности: смотреть по сторонам
  и играть вместе со взрослым.

## Секреты

- **Никогда не добавлять в репозиторий ключи, токены и пароли.**
  Репозиторий и сайт на GitHub Pages видны всем.
- Если для чего-то нужен ключ — сначала обсудить, можно ли обойтись без
  него.
