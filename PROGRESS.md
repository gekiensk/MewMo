# Прогресс MewMo (МяуМо)

Здесь отмечаем, какие этапы игры готовы, а какие ещё впереди.

## Этапы

- [x] **Этап 1: карта и точка игрока** — стартовый экран с напоминанием
  о безопасности, объёмная карта, точка игрока по GPS, капсулы вокруг
  игрока, кнопка «Где я?», демо-режим без GPS.
- [ ] **Этап 2: коты, а не просто счётчик** — каталог котов, свой кот
  в каждой капсуле, бесконечные капсулы, окно «Кот найден!».
  - [x] Подготовка: `logic.js` (чистая логика) и автотесты `tests/logic.test.js`
  - [x] Каталог котов (`cats.js`) — 8 котов, тесты `tests/cats.test.js`
  - [ ] Бесконечные капсулы
- [ ] **Этап 3: жесты** — Лапка, Коготь, Клубок.

## Как проверять

```
node --check logic.js        # и так для каждого .js файла
node --test                  # все автотесты
```

## Решения, принятые без меня

- **Команда запуска тестов — `node --test`, а не `node --test tests/`.**
  В установленной версии Node (22) команда с папкой `tests/` не работает:
  Node пытается открыть папку как файл и падает. Команда `node --test` без
  аргументов сама находит все файлы `*.test.js` (в том числе в `tests/`).
- **Тип Кометы — «космический».** В задании у Кометы нет типа (водный /
  лесной / городской), а тест требует, чтобы все поля были заполнены.
  Раз она «может встретиться где угодно», я дал ей отдельный тип.
- **Тип кота пока не зависит от места.** Водные коты не ищутся именно
  у воды — любой кот может оказаться в любой капсуле. Привязку к месту
  можно сделать позже.

## Идеи на потом

- **Сумеречные коты.** На прогулке появляются только примерно за час
  до заката, пока ещё светло. После заката их можно встретить только
  в режиме «Дом» — чтобы дети не гуляли в темноте. Время заката
  считать по координатам игрока прямо в браузере (по формуле, без
  внешних сервисов) — координаты никуда не отправляются.
