# MewMo (МяуМо)

Детская игра о котах-пришельцах, которые потерпели крушение на Земле.
Игрок находит их на карте и помогает вернуться домой.

## Что уже есть в игре

- Стартовый экран с напоминанием о безопасности.
- Объёмная карта (MapLibre GL JS + OpenFreeMap) с наклоном камеры, как в Pokémon GO.
- Розовая точка игрока, которая движется по GPS.
- Кнопка «Где я?» возвращает карту к игроку.
- Демо-режим: если GPS недоступен, игрок перемещается нажатием на карту.
- Вокруг игрока до 3 капсул на 60–250 м, в каждой свой кот (обычные,
  редкие и легендарные). Пойманную капсулу через 2–4 минуты сменяет
  новая. Капсула ближе 40 м светится — её можно открыть.
- Знакомство с котом: «Поймай сигнал» (даёт поблажку) и мини-игра своего
  типа: водные — «Поймай рыбок», лесные — «Повтори узор», городские —
  «Ритм», сумеречные — «Созвездие». Легендарные — две игры подряд.
  Победил — кот попадает в экипаж, и ты узнаёшь факт о настоящих кошках.
  Проиграл — кот смущается на минуту.
- Пройденные за день метры (только число, без координат) и задание
  «Пройди 500 м».
- Прогресс сохраняется в памяти браузера. Новый кот приносит деталь
  корабля, повторная встреча — 3 космические рыбки.
- Кнопка «Экипаж» открывает альбом: найденные коты и капитаны, рыбки,
  шкала «Ремонт корабля», кнопка «Начать заново».
- Маяки у детских площадок, парков, фонтанов, библиотек, музеев
  и арт-объектов (места берутся из данных карты). Маяк даёт рыбок
  ингредиенты для кухни и иногда деталь, потом 15 минут перезаряжается. Если мест рядом нет —
  появляются «Космические маяки».
- Тип кота зависит от места: у воды чаще водные, в парке — лесные,
  на улицах — городские.
- Потерявшиеся капитаны: когда в экипаже главы 5+ котов, у маяка
  появляется капитан (не чаще раза в день). Испытание — три мини-игры,
  нужно выиграть две; два помощника помогают в играх своего типа.
- Сумеречные коты: только в последний час до заката (закат считается
  прямо на телефоне, по формуле).
- У каждого кота свой нарисованный портрет (SVG в коде): скафандр
  цвета его типа и своя деталь — гаечный ключ, ночной колпак, экран…
- Мягкие пастельные цвета (контраст текста проверяется автоматически).
- Тихие мягкие звуки синтезируются прямо в браузере (Web Audio API), кот
  покачивается и прыгает от радости. При «уменьшить движение» анимаций нет,
  а движение в играх вдвое медленнее.
- Настройки (⚙️): звук «Выкл / Тихо / Обычно», вибрация, переключение
  «прогулка / дом».
  Раздел «Для взрослых» (вход через пример на умножение): ограничение
  времени игры в день, «Только режим „Дом“», какие данные хранит игра.
- Режим «Дом» — без карты и без геолокации: убежище корабля, гость
  раз в 6 часов, уровни дружбы в очках. **На прогулке собираешь — дома
  используешь:** панель из 4 занятий —
  - «Кухня»: из ингредиентов с прогулки готовишь угощения в 3 шага
    (смешать, слепить, испечь); у каждого кота любимое угощение;
  - «Ремонт»: найденные детали ставишь в корабль, собирая пазл;
  - «Игры»: «Лазерная указка» и «Мячик» с котом (+2 очка дружбы в день);
  - «Обстановка»: за рыбок покупаешь предметы и расставляешь их;
    аквариум, цветок, телескоп и радио зовут гостей своего типа.
- Ежедневные задания — в обоих режимах, видны в альбоме.
- Игру можно добавить на главный экран телефона (манифест и иконка).
- **Главы.** Глава 1: 10 котов и маленький корабль (20 деталей).
  Когда установлены все детали, в альбоме появляется «🚀 Запустить корабль» —
  сцена взлёта, значок «Спасатель 1 ранга» и глава 2 «Сигнал с орбиты»:
  12 новых котов, 2 новых капитана, большой корабль на 30 деталей
  и «отставшие» коты главы 1, которых ещё можно найти.
- Обучение «Как играть» при первом запуске (и в настройках) и подсказки
  в первых двух встречах с котами.
- Надёжный GPS: «Ищем спутники…» вместо мгновенного демо-режима,
  перезапуск слежения, когда игра снова на экране или координат нет
  30 секунд, окно с инструкцией, если геолокацию запретили.
- ⚙️ → «📍 Проверить GPS»: состояние GPS и журнал событий (без координат),
  отчёт можно скопировать и прислать разработчику.

## Как проверить игру в браузере

```
node tools/smoke.js
```

Скрипт сам запускает сервер, открывает игру в Chromium на экране телефона
и проходит основные сценарии. Нужен Playwright, установленный на компьютере
глобально (`npm install -g playwright` и `npx playwright install chromium`).

## Как проверить код

Нужен только [Node.js](https://nodejs.org/) (ничего устанавливать через npm не нужно).
В папке проекта:

```
node --test
```

Команда сама найдёт и запустит все тесты из папки `tests/`.

## Безопасность и данные

Координаты игрока используются только внутри браузера и никуда
не отправляются. В памяти браузера сохраняются только коты, рыбки,
детали, ингредиенты, угощения, обстановка, перезарядка маяков,
настройки, время игры и пройденные метры за день (только число), гости,
дружба и задания — без координат. В режиме «Дом» геолокация вообще
не запрашивается. Нет чата, рекламы и покупок за деньги (магазин
обстановки — только за игровых рыбок).

## Как открыть игру на телефоне

Геолокация в браузере работает только на сайтах с `https`, поэтому используем GitHub Pages:

1. В репозитории открой **Settings → Pages**.
2. В **Source** выбери **Deploy from a branch**, ветку `main` и папку `/ (root)`, нажми **Save**.
3. Через 1–2 минуты игра будет доступна по адресу `https://gekiensk.github.io/MewMo/`.
