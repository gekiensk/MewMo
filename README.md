# MewMo (МяуМо)

Детская игра о котах-пришельцах, которые потерпели крушение на Земле.
Игрок находит их на карте и помогает вернуться домой.

## Что уже есть в игре

- Стартовый экран с напоминанием о безопасности.
- Объёмная карта (MapLibre GL JS + OpenFreeMap) с наклоном камеры, как в Pokémon GO.
- Розовая точка игрока, которая движется по GPS.
- Кнопка «Где я?» возвращает карту к игроку.
- Демо-режим: если GPS недоступен, игрок перемещается нажатием на карту.
- Вокруг игрока всегда 5 капсул, в каждой свой кот (8 котов, обычные,
  редкие и легендарные). Капсула ближе 40 м светится — её можно открыть.
- Знакомство с котом: мини-игры «Поймай сигнал» и «Лапка, Коготь, Клубок»
  (до двух побед). Победил — кот попадает в экипаж, и ты узнаёшь факт
  о настоящих кошках. Проиграл — кот смущается на минуту.

## Файлы

| Файл | Что внутри |
| --- | --- |
| `index.html` | Структура страницы: карта, кнопки, стартовый экран, окно знакомства с котом |
| `style.css` | Внешний вид: цвета, шрифт, кнопки, игрок, капсулы, окно знакомства |
| `game.js` | Карта, GPS, перемещение игрока, капсулы |
| `encounter.js` | Окно знакомства с котом и мини-игры |
| `cats.js` | Каталог котов |
| `logic.js` | «Чистые» расчёты: расстояния, редкость, правила жестов, сигнал |
| `tests/` | Автотесты для `logic.js` и `cats.js` |
| `CLAUDE.md` | Правила проекта |
| `PROGRESS.md` | Что сделано, решения, проблемы, идеи |

## Как проверить код

Нужен только [Node.js](https://nodejs.org/) (ничего устанавливать через npm не нужно).
В папке проекта:

```
node --test
```

Команда сама найдёт и запустит все тесты из папки `tests/`.

## Как открыть игру на телефоне

Геолокация в браузере работает только на сайтах с `https`, поэтому используем GitHub Pages:

1. В репозитории открой **Settings → Pages**.
2. В **Source** выбери **Deploy from a branch**, ветку `main` и папку `/ (root)`, нажми **Save**.
3. Через 1–2 минуты игра будет доступна по адресу `https://gekiensk.github.io/MewMo/`.
