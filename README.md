# MewMo (МяуМо)

Детская игра о котах-пришельцах, которые потерпели крушение на Земле.
Игрок находит их на карте и помогает вернуться домой.

## Этап 1: карта и точка игрока

- Стартовый экран с напоминанием о безопасности.
- Объёмная карта (MapLibre GL JS + OpenFreeMap) с наклоном камеры, как в Pokémon GO.
- Розовая точка игрока, которая движется по GPS.
- Капсулы с котами вокруг игрока: подойди ближе 40 м и нажми на капсулу, чтобы найти кота.
- Кнопка «Где я?» возвращает карту к игроку.
- Демо-режим: если GPS недоступен, игрок перемещается нажатием на карту.

## Файлы

| Файл | Что внутри |

| `index.html` | Структура страницы: карта, кнопки, стартовый экран |

## Как открыть игру на телефоне

Геолокация в браузере работает только на сайтах с `https`, поэтому используем GitHub Pages:

1. В репозитории открой **Settings → Pages**.
2. В **Source** выбери **Deploy from a branch**, ветку `main` и папку `/ (root)`, нажми **Save**.
3. Через 1–2 минуты игра будет доступна по адресу `https://gekiensk.github.io/MewMo/`.
